# BLACK MIRROR ULTRA — Автоматизированная Алгоритмическая Торговая Система

---

## Краткое описание

BLACK MIRROR ULTRA — это корпоративная платформа автоматической торговли криптовалютными фьючерсами. Система объединяет обработку рыночных сигналов в реальном времени, многоагентный аналитический конвейер и арбитраж решений на базе LLM для выполнения дисциплинированных, основанных на правилах торговых операций без участия человека.

---

## Архитектура системы

Система работает как многоуровневый конвейер:

| Уровень | Компонент | Функция |
|---|---|---|
| Приём сигналов | TradingView Webhook | Рыночные алерты в реальном времени с ценой, RSI, Volume Oscillator |
| Анализ рынка | Indicator Engine | ATR, EMA, RSI, объём на основе живых свечных данных |
| Консенсус агентов | 5 аналитических агентов | Независимая оценка: технический, сентиментальный, риск, импульс |
| Движок решений | Arbiter (LLM) | Арбитраж Claude Opus 4.7 с адаптивным порогом голосования |
| Контроль рисков | RiskGuard | Лимиты дневной просадки, авто-пауза, расчёт размера позиции |
| Исполнение | Position Manager | Выставление ордеров, частичное закрытие, трейлинг-стоп |
| Отчётность | Telegram Gateway | Уведомления о сделках и решениях в реальном времени |

---

## Ключевые возможности

- **Многоагентный консенсус** — решения требуют согласования между независимыми аналитическими модулями; порог динамически масштабируется в зависимости от волатильности рынка
- **LLM-арбитраж** — Claude Opus 4.7 анализирует конфликтующие голоса агентов и выносит обоснованное финальное решение
- **Адаптивное управление рисками** — размер позиции на основе ATR; автоматическая остановка торговли при превышении дневного лимита убытков
- **Поддержка нескольких пользователей** — единый биржевой аккаунт с веерным исполнением для подключённых пользователей
- **Graceful degradation** — каждый агент отказывает независимо; конвейер продолжает работу с пониженной уверенностью

---

## Интеграции

- **Биржа**: Weex Futures (REST + WebSocket)
- **Источник сигналов**: TradingView Pine Script алерты
- **LLM-провайдер**: Anthropic Claude Opus 4.7
- **Данные сентимента**: CNN Fear & Greed Index
- **Уведомления**: Telegram Bot API
- **Хранилище**: SQLite (позиции, решения, рыночные снимки, события рисков)

|---|---|

## Наблюдаемость

Полный журнал аудита хранится по каждому решению: голоса агентов, оценки уверенности, рассуждения LLM, рыночный снимок, результат исполнения. Административный Telegram-канал получает отчёты о решениях в реальном времени, включая полную дискуссию агентов и итог арбитража.
